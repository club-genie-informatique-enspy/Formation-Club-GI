# Complete Course on Git and GitHub

Welcome to this complete and practical course designed to take you from a beginner to a competent and confident user of Git and GitHub. This project contains a series of structured lessons and practical workshops to master code versioning like a professional.

---

### Who is this course for?

This course is ideal for:

*   **Beginner developers** who have never used a version control system.
*   **Computer science students** who want to acquire a fundamental skill.
*   **Designers, project managers** or anyone working with developers and wanting to understand their workflow.
*   Those who have already used Git but want to **solidify their foundations** and learn best practices.

### Structure

The course is divided into two main parts:

1.  `/` (root): Contains the theoretical **lessons**, organized in a progressive manner.
2.  `exercises/`: Contains **practical workshops** to apply the concepts seen in the lessons.

### How to use this course?

1.  **Follow the lessons** in order, from 1 to 9.
2.  **Take the time to understand** the visual diagrams.
3.  **Complete the corresponding exercises** after seeing the associated lessons to put your knowledge into practice.
4.  **Don't hesitate to experiment!** The best way to learn Git is to use it.
