# 01 - Introduction to Git and GitHub

## What is Git?

Git is a free and open source distributed version control system designed to handle everything from small to very large projects with speed and efficiency.

### Basic Concepts

- **Repository**: A folder containing your project, including all files and the history of changes.
- **Commit**: A snapshot of the changes made to your files.
- **Branch**: An independent line of development.
- **Merge**: Combining changes from different branches.

## What is GitHub?

GitHub is a web-based platform that hosts Git repositories and provides collaboration tools.

### Key Features

- **Pull Request**: A request to merge changes from one branch to another.
- **Issue**: A way to track tasks, enhancements, and bugs.
- **Fork**: A copy of a repository that you can modify without affecting the original.
