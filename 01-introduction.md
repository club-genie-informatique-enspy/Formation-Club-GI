# Leçon 1 : Introduction à Git

Bienvenue dans ce cours sur Git et GitHub !

## Qu'est-ce que le versionnement ?

Imaginez que vous travaillez sur un projet important (un rapport, un site web, un programme). Vous enregistrez vos modifications, mais vous vous rendez compte que vous avez fait une erreur. Comment revenir en arrière ? Et si vous travaillez à plusieurs, comment fusionner les modifications de tout le monde sans créer de chaos ?

C'est là qu'intervient un **système de contrôle de version** (VCS en anglais). C'est un logiciel qui suit et gère toutes les modifications apportées à un ensemble de fichiers au fil du temps. Il vous permet de :

-   Consulter l'historique complet des changements.
-   Revenir à n'importe quelle version précédente.
-   Comparer les versions entre elles.
-   Travailler en parallèle sur différentes fonctionnalités (avec les branches).
-   Fusionner le travail de plusieurs personnes de manière organisée.

## Qu'est-ce que Git ?

**Git** est le système de contrôle de version le plus populaire au monde. Il est :

-   **Distribué** : Chaque développeur a une copie complète de l'historique du projet sur sa machine. Pas besoin d'être connecté à un serveur central pour travailler.
-   **Rapide** : La plupart des opérations (commit, branche, etc.) sont quasi instantanées.
-   **Performant** : Il est conçu pour gérer des projets de toutes tailles, des plus petits aux plus grands.
-   **Gratuit et Open Source**.

## Et GitHub dans tout ça ?

Si Git est l'outil qui gère l'historique, **GitHub** est une plateforme en ligne qui héberge des dépôts Git. C'est un service qui ajoute des fonctionnalités collaboratives au-dessus de Git :

-   **Hébergement de vos dépôts** : Une sauvegarde en ligne de votre code, accessible de n'importe où.
-   **Collaboration** : Outils pour relire le code, discuter des modifications et suivre les problèmes (les fameuses *Pull Requests* et *Issues*).
-   **Visibilité** : Permet de partager votre travail avec le monde entier et de découvrir d'autres projets.

En résumé :
-   **Git** : Le logiciel de versionnement sur votre machine.
-   **GitHub** : Le "réseau social" pour vos projets Git, qui facilite la collaboration et le partage.
