# Cours Complet sur Git et GitHub

Bienvenue dans ce cours complet et pratique conçu pour vous faire passer de débutant à utilisateur compétent et confiant de Git et GitHub. Ce projet contient une série de leçons structurées et d'ateliers pratiques pour maîtriser le versionnement de code comme un professionnel.

---

### À qui s'adresse ce cours ?

Ce cours est idéal pour :

*   Les **développeurs débutants** qui n'ont jamais utilisé de système de contrôle de version.
*   Les **étudiants** en informatique qui souhaitent acquérir une compétence fondamentale.
*   Les **designers, chefs de projet** ou toute personne travaillant avec des développeurs et souhaitant comprendre leur workflow.
*   Ceux qui ont déjà utilisé Git mais veulent **solidifier leurs bases** et apprendre les bonnes pratiques.

### Structure

Le cours est divisé en deux parties principales :

1.  `/` (racine) : Contient les **leçons** théoriques, organisées de manière progressive.
2.  `exercices/` : Contient des **ateliers pratiques** pour appliquer les concepts vus dans les leçons.

### Comment utiliser ce cours ?

1.  **Suivez les leçons** dans l'ordre, de 1 à 9.
2.  **Prenez le temps de comprendre** les schémas visuels.
3.  **Réalisez les exercices** correspondants après avoir vu les leçons associées pour mettre en pratique vos connaissances.
4.  **N'hésitez pas à expérimenter !** Le meilleur moyen d'apprendre Git est de l'utiliser.
